## 一、异象检验 vs 多因子模型

### 1.1 总纲：不是并列方法，而是同一循环的两端

- **异象检验 = 证伪环节**：拿新现象挑战现有模型，找解释不掉的 $\alpha$；
- **多因子模型 = 理论化环节**：把反复出现的异象吸收为新因子，让 $\alpha$ 归零；
- 循环：CAPM → 规模/价值异象 → FF3 → 动量/盈利/投资异象 → FF5 / q-factor → IPCA → ……

**关键理解**：异象是**相对基准模型**定义的——"X 是异象"必须说全"X 在模型 M 下是异象"。动量在 FF5 下仍是异象；盈利/投资类在 FF5/q 下大体被吸收。

### 1.2 异象检验的两个技术路线

1. **时序回归路线**：$R_{i,t}^{e} = \alpha_i + \beta^{\prime} f_t + \varepsilon_{i,t}$，检验 $H_0: \alpha=0$；单个组合 t 检验，一组组合 **GRS 联合检验**（见 2.4）。
2. **FM 截面路线**：$R_{i,t}^{e} = \lambda_{0,t} + \gamma_t^{\prime} z_i + u_{i,t}$，检验 $\bar{\gamma}$ 显著性 = 特征的**增量预测力**（控制已有因子暴露后）。

判定门槛：t > 3；样本外存活；成本后仍显著；有经济逻辑。

### 1.3 多因子模型：构造范式与评价标准

构造范式：① 排序法（FF3/FF5）；② 理论驱动（q-factor 的投资 CAPM、ICAPM 状态变量）；③ 数据驱动（PCA/RP-PCA、IPCA、autoencoder）。

模型比较工具箱：GRS 与平均 $|\alpha|$ · **spanning test**（$R^{new}=a+b^{\prime}R^{old}$，$a=0$ 且解释度高 → 可被复制、无增量）· 因子组合 Sharpe · 贝叶斯比较（见 4.4）· 测试资产选择本身决定检验力。

### 1.4 横向对比表

| 维度 | 异象检验 | 多因子模型 |
|---|---|---|
| 角色 | **证伪**：找模型解释不了的收益 | **建构**：用一组因子解释截面 |
| 对象 | 单个特征/组合的定价误差 $\alpha$ | 全部测试资产 $\alpha$ **联合为零** |
| 基准 | 相对某基准模型定义 | 自身就是基准 |
| 统计工具 | 时序回归 α / GRS；FM 截面 $\gamma$ | GRS、spanning、Sharpe、贝叶斯比较 |
| 失败模式 | 数据挖掘、p-hacking、拥挤衰减 | 因子动物园、过拟合、伪因子 |
| 实务含义 | **alpha 策略候选** | **beta 管理 / 风险模型 / 归因** |
| 结局 | 被吸收为因子，或衰减消失 | 被更新的模型替代 |

### 1.5 动态循环案例

CAPM → Banz (1981) 规模、BM 效应 → FF3 (1993) 吸收 → 动量（Jegadeesh-Titman 1993，至今未被 FF5 吸收）→ 盈利（Novy-Marx 2013）、投资类异象 → FF5 / q-factor (2015) → Stambaugh-Yuan (2017) 错误定价因子 → Kelly-Pruitt-Su (2019) IPCA。

### 1.6 深层张力：解释力 vs 获利性

- **模型的胜利 = 异象的死亡**：被吸收后，"异象收益"被重新标记为"因子暴露补偿"；
- 实务定性决定流程：风险论 → 因子中性对冲；错误定价论 → 视作 alpha 持有；
- **alpha 有半衰期**：McLean-Pontiff (2016)——发表后收益约降 58%（样本外已降 26%）。

## 二、异象检验的计量工具链

```
时序回归 α 检验（可交易因子专用，隐含 λ = f̄）
 ├─ 单组合：t 检验 → 标准误 → White（异方差）/ Newey-West（自相关）
 └─ 多组合：GRS 精确 F ‖ 夏普恒等式 ‖ 均值-方差张成检验（投资价值维度）

截面回归 FM 检验（任意因子通用）
 └─ EIV → Shanken 校正；截面相关 → FM 平均；γ̂ₜ 自相关 → NW
```

| 工具 | 检验对象 | 维度 | 关键假设 | 稳健替代 |
|---|---|---|---|---|
| 时序 α t 检验 | 单个异象组合 | 定价 | 可交易因子 | White / NW t |
| GRS | N 组合联合 | 定价 | iid 多元正态 | GMM、bootstrap |
| FM 截面 t | 特征边际溢价 | 定价 | 修正后近似 | NW + Shanken |
| 张成检验 (HK) | 新因子/资产 | **投资价值** | iid 正态（无 rf 加 Bι=ι） | GMM、bootstrap |

### 2.1 时序回归检验异象

$R_{i,t}^{e} = \alpha_i + \beta_i^{\prime} f_t + \varepsilon_{i,t}$，$H_0:\ \alpha_i = 0$。隐含 $\bar\lambda = \overline{f}$（不使用截面信息）→ **只适用于可交易因子**；宏观因子必须转截面回归。

### 2.2 White 估计量（异方差稳健）

$$\widehat{\mathrm{Var}}(\hat\beta) = (X'X)^{-1}\Big[\textstyle\sum_t x_t x_t^{\prime}\,\hat\varepsilon_t^2\Big](X'X)^{-1}\ (\mathrm{HC0})$$

小样本修正 HC1（自由度）、HC2、HC3（杠杆调整）。**只处理异方差，不处理自相关**；只改标准误，不动点估计。

### 2.3 Newey-West 估计量（HAC 稳健）

$$\hat\Omega = \hat\Gamma_0 + \sum_{l=1}^{L}\Big(1-\frac{l}{L+1}\Big)\big(\hat\Gamma_l + \hat\Gamma_l^{\prime}\big)$$

Bartlett 核保证半正定；$L=\lfloor 4(T/100)^{2/9}\rfloor$，重叠收益取 $L \geq$ 重叠月数；**$L=0$ 退化为 White**。适用：重叠持有期收益、FM 的 $\hat\gamma_t$ 序列。

### 2.4 GRS 检验

$$F = \frac{T-N-K}{N}\cdot\frac{\hat\alpha^{\prime}\hat\Sigma^{-1}\hat\alpha}{1+\bar{f}^{\prime}\hat\Sigma_f^{-1}\bar{f}} \sim F(N,\,T-N-K)$$

- 分子 = 残差逆协方差加权的定价误差；分母 = $1+\tilde\theta^2$（因子集最大夏普率平方）；
- **夏普恒等式**：$F = \frac{T-N-K}{N}\cdot\frac{\bar\theta^2-\tilde\theta^2}{1+\tilde\theta^2}$——GRS 检验的就是"加入测试资产后切点夏普是否显著提高"；
- 假设 iid 多元正态；违背时用 GMM 版（MacKinlay-Richardson 1991）或 bootstrap；GMM 版构造见 [因子投资学习笔记_2026-09-04.md](因子投资学习笔记_2026-09-04.md) §2.7。

### 2.5 截面 FM 检验的三个修正

**EIV → Shanken (1992)**：方差乘 $(1+c)$，$c=\hat\lambda^{\prime}\hat\Sigma_f^{-1}\hat\lambda$ = 因子组合夏普率平方（因子越强校正越狠）；**截面相关 → FM 逐期平均天然消化**；**$\hat\gamma_t$ 自相关 → NW**。

### 2.6 均值-方差张成检验（Huberman-Kandel 1987）

$R_t = a + Bf_t + \varepsilon_t$：

| 框架 | 张成成立条件 $H_0$ | 直觉 |
|---|---|---|
| 有 rf（超额收益框架） | $a = 0$ | 新资产 = 因子组合 + 零均值噪声，切点夏普不变 |
| 无 rf | $a=0$ **且** $B\iota_K=\iota_N$ | 整条前沿不变 |

- 有 rf 时张成检验 = GRS（夏普恒等式）；残差协方差奇异的扩展见 DeRoon-Nijman (2001)；
- 单因子版即 **spanning 回归**（FF 2015、Barillas-Shanken 2018 筛因子所用）；
- **定价增量 ≠ 投资增量**：新因子可能改善 GRS 却被现有因子张成（FF5 vs q-factor 的因子高度相关即此例）。

## 三、阿尔法检验深化：从"t 值显著"到"真 α 存在"

计量工具链（t、White/NW、GRS、FM+Shanken、张成检验）只回答"**统计上显著吗**"；完整的 α 检验补四个缺口：**经济显著性、肥尾、运气（多重检验）、样本外**。

### 3.1 统计显著性 ≠ 经济显著性

t 值衡量 $\alpha/\sigma_\alpha$，与"值不值得交易"无关。经济显著性看：

- **成本后年化 α**：扣除佣金、冲击成本、融券成本后的净残差收益；
- **信息比率** $\mathrm{IR}=\alpha/\sigma_\varepsilon$——分母是**残差波动**而非总波动，衡量每单位"模型解释不掉的风险"换来的超额收益；
- **容量与换手**：t 值再高，容量极小、月换手 200% 的策略落不了地。

**检验顺序**：先经济、后统计——顺序反了（先扫几百个 t 值大的组合再找解释）就是标准的数据挖掘流程。

### 3.2 肥尾与 bootstrap

月度收益尖峰厚尾，t 检验尾部概率失真；多空组合的 α 常由个别极端月驱动（危机月做空正好赚钱）。

```
bootstrap 流程：保留实际收益的肥尾形状 → 对残差/收益序列重采样
→ 每次重采样重估 α̂ → 得到 α 的经验分布 → 经验 p 值
```

- **块 bootstrap**（按块重采样）可保留自相关结构；
- **Kosowski-Timmermann-Wermers-White (2006)**：bootstrap 检验基金"明星"α——许多 t 值显著的流星在肥尾世界里并不稀奇；
- **Fama-French (2010) *Luck versus Skill***：在"所有基金真 α=0"世界 bootstrap 出纯运气 α 分布，与实际对比——多数基金 α≤0（费用后），真技能的证据在**持续性**而非单期 α。

本质优势：不依赖正态假设，直接回答"**这么大的 α 纯靠运气出现的概率**"。

### 3.3 多重检验：运气的数学

检验 $N$ 个因子，5% 水平下纯运气显著约 $0.05N$ 个；$N=400$（因子动物园规模）时"至少一个假显著"概率 $\approx 1$。

| 方法 | 控制目标 | 特点 |
|---|---|---|
| Bonferroni（门槛 $\alpha/N$） | FWER：至少一个假显著的概率 | 最严，大量误杀真因子 |
| Holm 步进 | FWER | 稍宽松，仍偏保守 |
| **BHY (2001)** | **FDR：显著结果中假阳性的期望比例** | 因子挖掘首选：容忍可控假阳性率，换取更多真发现 |

- **Harvey-Liu-Zhu (2016)**：对 316 个已发表因子做三重校正，新因子门槛 **t > 3.0**；
- **Deflated Sharpe Ratio**（Bailey-López de Prado 2014）：另一视角——回测出的最高夏普有多少只是"$N$ 次尝试的最大值"这一统计事实？按试验次数、样本长度、收益偏度折减后再看显著性。

### 3.4 样本外三重证据

| 证据 | 文献 | 发现 |
|---|---|---|
| 发表后衰减 | McLean-Pontiff (2016) | 发表后收益约降 58%（样本外已先降 26%）——套利资金进场 |
| 复制危机 | Hou-Xue-Zhang (2020) | 452 个异象用规范协议（市值加权、NYSE 断点、t>3）复制，大部分消失 |
| 历史样本外 | Linnainmaa-Roberts (2018) | 多数异象在"发表前样本"已弱 |

**可信度 = 统计检验 × 稳健性协议 × 样本外存活**，单靠 t 值的时代结束了。

### 3.5 条件 α 与择时

- **Ferson-Schadt (1996)**：$\beta$ 随状态变量（股息率、期限利差）变化；无条件回归会把"条件 β 的时变"误判成 α——很多"择时 α"是幻觉来源；
- 择时检验：**Treynor-Mazuy (1966)** 加二次项 $\gamma f_t^2$（凸性收益 = 择时）；**Henriksson-Merton (1981)** 加 $\max(f_t,0)$ 哑变量。

## 四、贝叶斯方法：从"数据有多意外"到"我该信多少"

### 4.1 三个频率派痛点

① **p 值误读**：$p=0.03$ 不是"因子为真的概率 97%"；频率派给不出 $P(\text{因子有效}\mid\text{数据})$；
② **多重检验只能事后统一惩罚**：t>3 一刀切，无法区别对待"有经济逻辑"与"纯挖掘"的因子；
③ **不确定性无法传导**：点估计的误差进不了配置决策——均值-方差优化因此变成"误差最大化器"。

### 4.2 贝叶斯回归与收缩：先验的自然结果

$$\text{后验} \propto \text{似然} \times \text{先验}，\qquad \text{后验均值} = \text{先验均值与 OLS 估计的精度加权平均（收缩）}$$

- **Stein 悖论**（Efron-Morris 1977）：同时估计 ≥3 个均值时，向整体均值收缩的总 MSE 优于各自样本均值；James-Stein 估计量 = 经验贝叶斯。**频率派的收缩是特设技巧，贝叶斯的收缩是定理**；
- 实务落点：因子载荷/预期收益收缩（防单期噪声 β）；**Ledoit-Wolf (2004)** 协方差收缩（样本协方差向结构化目标收缩 → 组合权重稳定）；Ridge/LASSO 正则化 = 高斯/拉普拉斯先验。

### 4.3 α 检验的贝叶斯版

- **Kosowski-Naik-Teo (2007)**：α 来自"有技能/无技能"混合分布（先验），结合数据输出每只基金的**后验 $P(\alpha>0)$**——把"显著/不显著"升级为"跑赢的信念概率"；
- **Pastor-Stambaugh (2000, 2002)**：投资者立场的贝叶斯基金评价——标准不是 α 的 t 值，而是持有该基金相对基准的**期望效用提升**；
- **FF (2010) 的贝叶斯式解读**：bootstrap 的"运气分布" ≈ 显式化"多数基金无技能"先验——频率派做法里藏着一个贝叶斯假设。

### 4.4 模型不确定性与贝叶斯模型比较（BMA）

频率派困境：GRS 只能"不拒绝"、嵌套比较尴尬、结论依赖测试资产选择。贝叶斯解法：

- **Barillas-Shanken (2018)**：给 $M$ 个候选定价模型算**后验模型概率**；关键设计：候选因子**既当因子又当测试资产**——解释不了别家因子则后验被压低（张成检验逻辑的贝叶斯化）；结论：六因子（Mkt, SMB, HML, RMW, CMA, UMD）；
- **BMA（贝叶斯模型平均）**：不押注冠军模型，按后验概率加权所有模型做推断——对模型不确定性本身稳健。

### 4.5 Black-Litterman：实务落点

$$E[R] = \big[(\tau\Sigma)^{-1} + P^{\prime}\Omega^{-1}P\big]^{-1}\big[(\tau\Sigma)^{-1}\,\Pi + P^{\prime}\Omega^{-1}Q\big]$$

- **先验** $\Pi$：市场均衡隐含收益（CAPM 反推）；**观点** $(P,Q)$：因子信号（$Q$ = 信号预期超额收益，$P$ = 作用资产）；$\Omega$：观点置信度；
- **与 α 检验闭环**：$\Omega$ 由 α 统计量（t 值/IR）映射——统计上越硬的信号权重越大，弱信号被收缩回均衡。**α 检验的输出即 BL 的输入**；
- 治好的病：均值-方差优化对期望收益的极端敏感（微小输入变化 → 疯狂多空权重）。

### 4.6 先验 = 反数据挖掘的防线

**Ioannidis (2005) 逻辑**：事前概率低 × 检验力低 → 大部分"显著"结果是假的。贝叶斯把它量化：给"有经济逻辑、跨市场一致、有理论支撑"的因子宽先验，给"纯排序试出来的"紧先验——这是统一 t>3 做不到的**因子间差异化惩罚**，也是贝叶斯对因子投资最独特的贡献。

### 4.7 频率派 vs 贝叶斯：任务对照

| 任务 | 频率派工具 | 贝叶斯对应 |
|---|---|---|
| α 显著性 | t / GRS / bootstrap | 后验 $P(\alpha>0)$ |
| 多因子挖掘 | Bonferroni / BHY、t>3 | 先验 odds（按经济逻辑差异化） |
| 模型比较 | GRS / spanning / 嵌套 F | BS 后验概率 / BMA |
| 参数估计 | OLS + White/NW | 收缩后验均值（JS、Ledoit-Wolf） |
| 配置决策 | 点估计 → MV 优化 | Black-Litterman 后验收益 |

### 4.8 更新后的完整工具链（三层）

```
【检验层·频率派】
时序 α → t（White/NW）→ GRS（联合 = 张成检验的夏普形式）
截面 FM → NW + Shanken
【α 检验深化】
统计显著性 → 经济显著性（IR/成本后）→ bootstrap（肥尾）
→ 多重检验（BHY、t>3、deflated SR）→ 样本外（MP/HZX/LR）
【贝叶斯层】
先验（经济逻辑/市场均衡）× 数据 → 后验
  α：P(α>0)｜模型：BS 六因子/BMA｜参数：收缩｜配置：Black-Litterman
```

## 六、一句话总结
