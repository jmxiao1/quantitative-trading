## 一、组合排序法（Portfolio Sort）—— 因子检验的"第一语言"

回归法（01笔记）是"**用一条线拟合收益与特征的关系**"；组合排序法（Portfolio Sort）则是"**按特征把股票分成几堆，比较各堆的收益**"。后者不假设线性、不假设正态，是因子投资里最古老、最稳健、也最接近真实建仓方式的检验手段。

### 1.1 基本流程（五步）

```
① 每期 t：按因子值把股票排序
② 分组：五分位（quintile）/ 十分位（decile）
③ 计算各组下期（t→t+1）收益
④ 构造多空组合：L/S = 顶组收益 − 底组收益
⑤ 检验：多空组合收益对因子模型回归 → 看 α 与 t 值
```

**关键**：多空组合（long-short）是"**买高因子、卖低因子**"的自融资组合。它的 α（对市场或 FF3 回归后的截距）才是因子"在已有模型解释之外"的净贡献——这一点与异象检验（9月3日笔记）完全同构。

### 1.2 四个必须明确的"设计选择"

| 设计项 | 选项 | 权衡 |
|---|---|---|
| **分组数** | 五分位 / 十分位 | 组越多顶底越"纯粹"（多空价差越大），但组内股票少、噪声大、换手高 |
| **断点** | NYSE 断点 vs 全体股票断点 | NYSE 大市值为主，断点更稳定、避免被海量小票主导；HXZ (2020) 复制协议即用 NYSE 断点 |
| **加权** | 等权 vs 市值加权 | 等权分散、小票贡献大（容量低）；市值加权贴近可投资性、但可能被大票主导 |
| **再平衡** | 月度 / 季度 / 年度 | 频率高 → 换手高 → 成本侵蚀；频率低 → 因子信号"过期" |

### 1.3 单变量排序 vs 双变量排序（控制变量）

- **单变量排序**：只按目标因子分堆。问题：因子之间高度相关（小票常是价值股），单变量会"串味"。
- **双变量排序（double sort）**：先按**控制变量**（通常是规模）分 5 组，再在**每个规模组内**按目标因子分 5 组，最后把同一目标因子组**跨规模组平均** → 得到**规模中性化**的目标因子组合。
- **独立排序 vs 条件排序**：
  - **独立排序（independent sort）**：两个变量各自独立取分位，交叉成网格。缺点：网格里组合股票数可能不均。
  - **条件排序（dependent / conditional sort）**：先分控制组，再在组内取目标因子分位。保证每组等股票数，是主流做法。
- **与回归的对应**：双变量排序 ≈ 回归里"加入规模控制变量后的边际效应"。排序法是非参版、回归法是参数版，两者应互相印证（稳健性协议要求两者都显著）。

### 1.4 组合排序 vs 回归法

| 维度 | 组合排序 | 回归法 |
|---|---|---|
| 假设 | 无（非参数） | 线性、误差独立同分布 |
| 稳健性 | 对极值、非线性稳健 | 对极值敏感（需去极值） |
| 控制变量 | 双变量排序（有限几个） | 轻松加入大量控制变量 |
| 直观性 | "买什么"一目了然 | 系数经济含义需翻译 |
| 结论 | 分组的**单调性**与顶底价差 | 一个斜率系数 + t 值 |
| 实务 | 直接对应真实多空组合 | 需再转成组合 |

> **经验法则**：先看排序（收益是否随因子**单调**递增/递减），再跑回归（确认显著性与稳健性）。只有排序单调、回归显著、样本外存活的因子才可信。

## 二、因子构造与数据处理：把"原始指标"炼成"可交易的因子"

原始数据（财务指标、市值、收益率）不能直接用，要经过**去极值 → 标准化 → 中性化 →（正交化）**的流水线。

### 2.1 去极值（Winsorize / Truncate）

- **目的**：少数极端值会毁掉截面回归和排序（一个 B/M=10^6 的股票拖垮整列）。
- **方法**：
  - **缩尾（winsorize）**：把超出 $1\%/99\%$ 分位的值**拉回边界**（保留极端值的排序信息但不放大其数值）。
  - **截尾（truncate）**：直接删除极端值。
  - **MAD 法**：$x$ 超出 $\text{median}\pm k\cdot\text{MAD}$ 则缩到边界，对厚尾分布更稳健。
- 常用：横截面内 1%/99% 缩尾，或 mean ± 3σ。
- **教材 §3.1 深度展开**：数据来源 Tushare、量价处理（复权/停牌/最少交易日）、财务处理（PIT/报告期/TTM/单季度）、因子构建全流程 → [因子投资学习笔记_2026-09-05.md](因子投资学习笔记_2026-09-05.md)

### 2.2 标准化（z-score）

$$z_i = \frac{x_i - \mu}{\sigma} \quad (\mu,\sigma\ \text{为当期横截面均值/标准差})$$

- **目的**：让不同量纲的因子（市值 vs 利润率）可比、可加，也便于构造多因子复合信号。
- 注意：标准化是**每期横截面内**做，不能跨期混用。

### 2.3 中性化（Neutralization）—— 去"污染"

因子之间天然相关（小票爱是价值股），导致"价值因子"里其实混着"规模暴露"。中性化 = 把目标因子对**不希望暴露的变量**做横截面回归，**取残差**：

$$x^{\text{neu}} = \text{residual of } \big[x_i = \alpha + \sum_c \gamma_c D_{i,c} + \delta \ln(\text{ME}_i) + \varepsilon_i\big]$$

- **行业中性化**：减去行业哑变量 → 因子不再有行业偏向。
- **市值中性化**：减去对数市值 → 因子不再有规模偏向。
- **为什么中性化**：① 避免因子收益被"纯行业/纯市值"驱动（伪因子）；② 让组合在目标暴露上集中、在其他维度上中性，便于风险控制。
- **代价**：中性化可能"倒掉洗澡水"——如果因子与规模**本就共享同一风险溢价**，强中性化会误删真信号。实务中按策略目标选择。

### 2.4 正交化（Orthogonalization）

- **目的**：去掉新因子与**已有因子**的共线性（如把动量对价值正交，得到"纯动量"）。
- **方法**：横截面回归取残差（与中性化同一机制，只是回归元换成已有因子），或 Gram-Schmidt。
- **用途**：构造正交多因子组合，避免信号重复下注。
- **深入**：施密特（顺序）vs 对称（Löwdin）正交化、纯因子组合 → [因子投资学习笔记_03.md](因子投资学习笔记_2026-09-04.md) §一

## 三、主要因子分类：因子动物园导览

以下按"风险/错误定价"两大解释与构造方法，整理七大类最成熟的因子（均有大量文献支撑）。

### 3.1 规模（Size）

- **度量**：市值 $\ln(\text{ME})$；小市值 − 大市值。
- **文献**：Banz (1981) 小市值溢价；FF 的 SMB。
- **争议**：小市值溢价在 1980 年代后大幅减弱，且对加权方式、微盘股剔除极其敏感（HXZ 2020 复制中消失最彻底的一类）。

### 3.2 价值（Value）

- **度量**：账面市值比 B/M（FF 1992）、盈利价格比 E/P（Basu 1983）、现金流价格比 CF/P、股息率 D/P。
- **逻辑**：低价买"被低估"的股票；风险论（困境股）vs 行为论（过度反应）。
- **因子组合**：HML（高 B/M − 低 B/M）。
- **深度讲解**：起源（Graham→Basu→FF）、成因（风险 vs 行为）、全球+ A 股实证 → [因子投资学习笔记_04.md](因子投资学习笔记_04.md) §二

### 3.3 动量（Momentum）

- **度量**：过去 2–12 个月累计收益，**跳过最近 1 个月**（避开短期反转），即"12-1 动量"。
- **文献**：Jegadeesh-Titman (1993)；UMD（赢家 − 输家）。
- **地位**：**至今未被 FF5/q 吸收**的异象（9月3日笔记 1.5），学术界公认最难解释、样本外最强的因子之一。
- **反转变体**：短期（1 个月）反转、长期（3–5 年）反转。
- **深度讲解**：起源（Levy→Jegadeesh-Titman）、成因（行为主导）、动量崩溃、A 股反转 → [因子投资学习笔记_04.md](因子投资学习笔记_04.md) §三

### 3.4 质量 / 盈利（Quality / Profitability）

- **度量**：毛利/资产 GP/A（Novy-Marx 2013）、ROE、ROA、应计利润（accruals，Sloan 1996——应计越低越好）。
- **因子组合**：RMW（Robust − Weak，稳健盈利 − 疲弱盈利）。
- **逻辑**：高盈利、低应计的公司质量高；投资 CAPM 认为高盈利是"高预期回报"的来源。
- **深度讲解**：q 理论均值公式推导、度量谱系（ROE/ROA/GP/A/扣非）、应计异象、FF5 构造、A 股落地代码 → [因子投资学习笔记_05.md](因子投资学习笔记_05.md) §三

### 3.5 投资（Investment）

- **度量**：总资产增长率（asset growth，Cooper-Gulen-Schill 2008）、投资/资产 I/A。
- **因子组合**：CMA（Conservative − Aggressive，保守 − 激进）。
- **逻辑**：高投资的公司未来回报低（投资 CAPM：高折现率 → 高投资 → 高预期回报……实际方向是"投资高 → 未来收益低"，与价值逻辑同源）。
- **深度讲解**：度量谱系、投资 CAPM（折现率→投资决策）、A 股区分真投资/乱扩张、盈利×投资质量矩阵 → [因子投资学习笔记_05.md](因子投资学习笔记_05.md) §四

### 3.6 低波动（Low Volatility）

- **度量**：市场 β、特质波动率 IVOL。
- **文献**：低 β 异象（Frazzini-Pedersen 2014 的 Betting Against Beta）、低 IVOL 异象（Ang-Hodrick-Xing-Zhang 2006）。
- **逻辑**：低风险股票反而高收益，挑战"高风险高回报"；解释包括杠杆约束、彩票偏好。
- **实务地位**：低波是量化与 Smart Beta 最常用的"防御型"因子。

### 3.7 成长（Growth）

- **度量**：盈利/销售增长率、分析师预期修正。
- **地位**：与价值对立互补；成长因子单独长期表现弱于价值，但在"质量成长"复合中常用。

### 3.8 因子分类总表

| 因子 | 代表度量 | 代表因子组合 | 核心文献 | 主流解释 |
|---|---|---|---|---|
| 规模 | 市值 | SMB | Banz (1981) | 风险 / 流动性 |
| 价值 | B/M, E/P, CF/P | HML | Basu (1983), FF (1992) | 风险 + 行为 |
| 动量 | 12-1 收益 | UMD | Jegadeesh-Titman (1993) | 行为为主 |
| 盈利 | GP/A, ROE | RMW | Novy-Marx (2013) | 投资 CAPM |
| 投资 | 资产增长, I/A | CMA | Cooper et al. (2008) | 投资 CAPM |
| 低波 | β, IVOL | BAB | Frazzini-Pedersen (2014) | 杠杆约束 / 彩票 |
| 质量 | 应计, 毛利 | QMJ | Sloan (1996) | 行为 + 风险 |

## 四、多因子模型的构造细节：FF3 / FF5 / q-factor

01、02笔记讲了模型**怎么用**（检验 α、比较模型），这里补**怎么造**。

### 4.1 Fama-French 三因子（FF3, 1993）的 2×3 排序

```
按市值 2 组（中位数分 Small/Big）× 按 B/M 3 组（30/70 分位）
→ 6 个组合：S/L, S/M, S/H, B/L, B/M, B/H

SMB = 三个小市值组均值 − 三个大市值组均值
HML = 两个高 B/M 组均值 − 两个低 B/M 组均值
```

- **设计意图**：SMB 的构造**消掉 B/M 的干扰**（S 组和 B 组各含高中低 B/M），HML 同理消掉市值干扰——双变量排序的"组间平均"思想。
- 组合**市值加权**、**月度再平衡**、用 **NYSE 断点**。

### 4.2 Fama-French 五因子（FF5, 2015）

- 在 FF3 基础上加 **RMW**（盈利 3 组：稳健 − 疲弱）与 **CMA**（投资 3 组：保守 − 激进）。
- 构造仍用 2×3 排序（规模 2 × 盈利 3 × 投资 3），各因子组合跨其他维度平均。
- **重要发现**：加入 RMW 后，HML 变得**冗余**（价值因子被盈利/投资因子吸收）——这是"模型吸收异象"的教科书案例。

### 4.3 q-factor 模型（Hou-Xue-Zhang 2015）

- 四因子：**市场 + 规模（ME）+ 投资（I/A）+ 盈利（ROE）**。
- 完全从 **q 理论（投资 CAPM）** 推导，不含价值因子；实证上与 FF5 高度相关、解释力相当。
- 与 FF5 的"因子高度相关"正是 9月3日笔记 2.6 张成检验的例子：一个模型改善 GRS 却可能被另一个张成。

### 4.4 构造的通用"防前视"协议

- **财务数据滞后**：用 t-6 月（年报）及更早的财务数据匹配 t 月收益，确保信息在期末**已知**（公告日对齐，9月1日笔记 79 行"好特征标准"）。
- **NYSE 断点 + 市值加权 + 月度再平衡**：HXZ (2020) 复制协议的标准做法，避免"用后视镜选断点"。

## 五、组合优化与风险模型：从"信号"到"持仓"

因子检验回答"因子有没有用"，组合构建回答"**怎么把多个因子变成一份能执行的持仓**"。

### 5.1 均值-方差优化（Markowitz）

$$\max_w \ w^{\prime}\mu - \frac{\lambda}{2} w^{\prime}\Sigma w \quad \text{s.t.} \ \sum_i w_i = 1$$

- **经典病**：解对 $\mu$（预期收益）的估计误差**极端敏感**——微小的输入变化 → 疯狂的多空权重（Michaud 1989 称之为"误差最大化器"）。
- **药方**：① 预期收益收缩/贝叶斯（Black-Litterman，02笔记 4.5）；② 协方差收缩（Ledoit-Wolf）；③ 加约束。

### 5.2 约束（让优化"可执行"）

| 约束 | 作用 |
|---|---|
| 满仓 $\sum w=1$ | 资金完全配置 |
| 多头 $w\ge 0$ | 禁止做空（多头基金） |
| 换手约束 $\|w-w_0\|_1\le c$ | 限制交易成本 |
| 行业中性 | 行业权重 ≈ 基准，纯赚选股 α |
| 风格/因子暴露约束 | 目标暴露有界，控制偏离 |
| 跟踪误差约束 | 相对基准风险有上限 |

### 5.3 Barra 风险模型（多因子风险分解）

- **已知暴露、估因子收益**（9月1日笔记第五节"Barra 路线"的落地）：
  $$r = X f + \varepsilon，\quad \Sigma = X\,\Sigma_f\,X^{\prime} + D$$
  其中 $X$ = 行业哑变量 + 风格因子暴露，$f$ = 因子收益（逐期截面回归估出），$\Sigma_f$ = 因子协方差，$D$ = 特质风险对角阵。
- **用途**：风险分解（多少来自行业、多少来自风格、多少来自选股）、跟踪误差归因、组合风险预演。

### 5.4 启发式排序 vs 优化器

| | 启发式（排序加权） | 优化器 |
|---|---|---|
| 做法 | 按综合得分排序，前 N 只按权重买入 | 显式最大化目标函数 + 约束 |
| 优点 | 简单、稳健、透明 | 能处理协方差、精确满足约束 |
| 缺点 | 忽略协方差、约束粗 | 需稳健输入，否则误差放大 |

实务中常**混合**：用优化器做"跟踪误差约束下的因子暴露最大化"，用收缩估计提供输入。

## 六、因子择时：因子收益本身可预测吗？

因子择时 = 预测**因子收益**（而非个股收益）的高低，动态调因子权重。

### 6.1 三条择时路线

| 路线 | 信号 | 逻辑 |
|---|---|---|
| **估值择时** | 因子顶底组的估值价差（如价值因子的 B/M 价差） | 价差高 → 因子被低估 → 未来因子收益高 |
| **动量择时** | 因子自身近期收益 | 因子收益有短期延续性 |
| **宏观择时** | 利率、通胀、经济周期、期限利差 | 因子收益随宏观状态轮动（价值在通胀/复苏期强，动能在转折期崩） |

### 6.2 为什么择时极难

- 因子收益的**时序可预测性远弱于截面**（截面有大量股票、时序只有一条因子收益序列）——样本极少，容易过拟合。
- 择时本身引入**新的估计误差**：猜错时机比一直持有更糟（错过因子的"爆发月"代价巨大）。
- **结论**：多数实务采用"**低频率、弱幅度**"的估值择时 + 纪律性再平衡，而非激进预测。

## 七、拥挤度（Crowding）：因子的"容量上限"

### 7.1 定义

同一因子被过多资金追逐 → 标的被买贵 → 未来收益下降，且遇赎回/去杠杆时**同步踩踏**（2007 年 8 月量化危机、2020 年 3 月价值因子挤兑）。

### 7.2 测量指标

| 指标 | 含义 |
|---|---|
| 估值价差 | 因子顶底组估值差距被拉得过大 → 拥挤信号 |
| 做空兴趣 / 借券费率 | 空头拥挤 |
| 因子间相关性上升 | 不同"因子"其实买了同一批股票 → 伪分散 |
| 持仓集中度 / 换手 | 资金扎堆 |
| 拥挤度分数（如 MSCI/AQR） | 综合以上打包 |

### 7.3 后果与应对

- 后果：McLean-Pontiff 发表后衰减（资金进场）、崩盘风险、容量上限（小因子容量小更易挤）。
- 应对：**分散化**（多因子、多市场）、**监控价差**、**容量预算**、**逆向**（拥挤时降低仓位）。

## 八、交易成本与执行：从"纸面 α"到"净 α"

### 8.1 成本的构成

| 成本 | 说明 |
|---|---|
| 佣金 + 税费 | 显性，可精确计算 |
| 买卖价差（spread） | 隐性，小盘/低流动性股更大 |
| 冲击成本（market impact） | 大单推动价格，与订单规模、换手相关 |
| 融券成本（shorting cost） | 多空组合的做空腿特有，有时借不到券（借券失败） |

### 8.2 成本如何"杀死"因子

- 换手率是成本的第一驱动；**高换手因子（动量、短期反转）的纸面收益被成本侵蚀最严重**。
- 很多"纸面异象"扣成本后消失（Novy-Marx-Velikov 2016 等）；只有**容量大、换手低、成本后仍显著**的因子才可投资。
- 9月1日笔记"好特征最好是慢变量"（自测题 5）的落地：慢变量 → 低换手 → 低成本 → 净收益可兑现。

## 九、机器学习与因子投资：从"人工找因子"到"数据找因子"

### 9.1 惩罚回归（正则化）

- **Ridge（L2）**：系数收缩但不置零——对应高斯先验；**Lasso（L1）**：收缩并**变量选择**——对应拉普拉斯先验；**Elastic Net**：两者折中。
- 用途：在**成百上千个特征**上回归收益，自动选重要特征（02笔记 4.2 已指出正则化 = 贝叶斯收缩的特例）。

### 9.2 降维

- **PCR（主成分回归）**：PCA 提主成分再回归。
- **PLS（偏最小二乘）**：Kelly-Pruitt (2013) 用它把 26 个特征压缩成 1 个因子。
- **RP-PCA（风险溢价 PCA）**：Lettau-Pelger (2020)，在 PCA 目标里加"均值"信息，比传统 PCA 更会找定价因子。
- **IPCA（工具化 PCA）**：Kelly-Pruitt-Su (2019)——特征是**时变暴露**的载荷（01笔记 77 行"characteristics are covariances"的正式实现）。

### 9.3 树模型与神经网络

- **树**：随机森林、梯度提升（GBM/XGBoost）——擅长非线性、交互、缺失值。
- **神经网络**：深度前馈，自动学特征交互。
- **Gu-Kelly-Xiu (2020) "Empirical Asset Pricing via Machine Learning"**：用几十种 ML 方法预测个股收益，发现——
  ① 神经网络与树模型表现最好；② 收益可预测性**集中在流动性差、套利困难的小盘股**（套利限制的证据）；③ ML 的样本外 R² 虽低但**经济显著**（多空组合夏普远超线性）。
- **一句话**：ML 不做假设、自动交互，但**过拟合风险与可解释性**是最大代价——用样本外、经济显著性、稳健性三重把关（与 02笔记"可信度 = 统计 × 稳健 × 样本外"一致）。

### 9.4 方法论速查

| 方法 | 何时用 | 陷阱 |
|---|---|---|
| Ridge/Lasso | 高维线性、变量选择 | 正则参数需调、Lasso 不稳定 |
| PCR/PLS/RP-PCA | 提取定价因子、降维 | 主成分未必是"定价"成分 |
| IPCA | 特征驱动时变暴露 | 实现复杂、需大面板 |
| 树/神经网络 | 非线性、交互、大规模特征 | 过拟合、黑箱 |

## 十一、一句话总结（补充）

> 组合排序法是**因子检验的第一语言**（非参、稳健、贴近建仓），回归法是它的参数版；
> 因子从原始数据到可交易，要过**去极值 → 标准化 → 中性化 → 正交化**四道工序；
> 七大类因子（规模/价值/动量/盈利/投资/低波/质量）各有构造与解释，FF3/FF5/q-factor 用 **2×3 排序**把它们装进模型；
> 而从"因子有效"到"净赚到钱"，中间隔着**组合优化、风险模型、择时、拥挤与交易成本**五道现实关卡——机器学习扩展了找因子的能力，却改变不了"样本外、成本后、不拥挤"这同一把尺子。
