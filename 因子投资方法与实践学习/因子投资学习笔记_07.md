## 一、总览：盈利与投资为什么"成对"

盈利因子和投资因子是 FF5 在 FF3 基础上**新增的两根因子**，共同对应 **q 理论（投资 CAPM）** 的预测，且**天生互补、概念上成对**：

| | 盈利因子 | 投资因子 |
|---|---|---|
| **代表性因子** | RMW（Robust − Weak） | CMA（Conservative − Aggressive） |
| **度量** | 毛利率、ROE、ROA | 资产增长率、投资/资产 I/A |
| **指向** | **高盈利**的公司收益高 | **低投资**的公司收益高 |
| **合成** | 高盈利 + 低投资 = **"高质量"公司** | |
| **共同源头** | q 理论 / 投资 CAPM | |

**关键联系**：FF5 加入 RMW、CMA 后，**HML（价值）变得冗余（redundant）**——因为价值与盈利/投资高度相关（尤其是 CMA 与 HML 的相关系数高达 **0.7 左右**）。这正是 9/4 笔记讲 HML 冗余、以及正交化"相关性导致冗余"的现实案例。**理解盈利与投资因子，某种程度就是理解"价值溢价从哪里来"。**

**重要区分**：盈利和投资是**定价（pricing）因子**——解释横截面收益的**理性差异**，而非"赚钱的套利异象"。这与价值/动量有本质不同（后者成因存在争议）。**FF5/q-factor 愿意吸收盈利/投资，却吸收不了动量**，根源就在这里。

## 二、投资 CAPM（q 理论）：把"直觉"写成模型【新增】

原笔记只讲了文字直觉，这里补上正式推导——**这是理解盈利/投资因子为什么"成对出现"的关键**。

### 2.1 企业的投资决策问题

企业在 t 期选择投资 $I_t$，资本按 $K_{t+1}=(1-\delta)K_t+I_t$ 积累（$\delta$ 为折旧率）。企业最大化股东价值：

$$
\max_{\{I_t\}}\ \mathbb{E}\left[\sum_{t} M_{t+1}\,\Pi(K_t, I_t)\right]
$$

其中 $M_{t+1}$ 是随机贴现因子（SDF，9/4 笔记），$\Pi$ 是扣除调整成本后的利润。

**一阶条件**（对 $I_t$ 求导）给出：

$$
\mathbb{E}_t\big[M_{t+1}\cdot \mathrm{MR}_{t+1}\big] = 1
\qquad\Longleftrightarrow\qquad
\mathbb{E}_t\big[r^I_{t+1}\big] = \underbrace{\text{折现率}}_{\text{= 预期股票收益}}
$$

**经济含义**：**企业投资的边际回报率 = 资本成本 = 预期股票收益**。这不是假设，而是最优化的必然结果。

### 2.2 均值形式：两个因子的统一公式

把上式写成可实证的均值形式（Hou-Xue-Zhang 2015；Liu-Wang-Zhang）：

$$
\boxed{\ \mathbb{E}_t\big[R^e_{t+1}\big] = \frac{\mathbb{E}_t\big[\Pi_{K,t+1}\big]}{1 + a\big(I_t/K_t\big)}\ }
$$

- **分子** $\Pi_K$ = 资本的**边际盈利**，实证代理是 **ROE / 毛利率**；
- **分母** $a(I_t/K_t)$ = **调整成本**，实证代理是 **投资/资产 I/A**（投资越多，边际调整成本越高）。

**两个推论"自动"跳出来**：

| 变量 | 变化 | 对预期收益的影响 | 对应因子 |
|---|---|---|---|
| 盈利 $\Pi_K$ ↑ | 分子变大 | **预期收益 ↑** | **盈利因子**（正向） |
| 投资 $I/K$ ↑ | 分母变大 | **预期收益 ↓** | **投资因子**（反向） |

> 💡 **这就是"盈利与投资成对"的根本原因**——它们是同一个方程式的分子与分母。**不是两个独立发现的异象，而是同一个理论的两翼。**

### 2.3 为什么它叫"投资 CAPM"

传统 CAPM 从**消费**出发（消费 β 决定预期收益）；投资 CAPM 从**生产**出发（投资的一阶条件决定预期收益）。Hou-Xue-Zhang 等人主张：**生产侧的"投资 CAPM"比消费侧 CAPM 更贴近现实**——因为企业的投资决策是直接可观测、且直接连接股票收益的。

**与 FF5 的关系**：FF5 是"实证驱动"（先发现因子、再造模型）；q-factor 是"理论驱动"（先从 q 理论推导出因子、再实证检验）。**两者殊途同归**——这反过来增强了盈利/投资因子的可信度。

## 三、盈利因子（§3.4）

### 3.1 起源：从"盈利公告"到"盈利因子"

| 时间 | 里程碑 | 内容 |
|---|---|---|
| **1968** | Ball-Brown | 盈利公告能**解释股价变动**（盈余信息含量） |
| **1977** | Basu | E/P（盈利收益率）效应——盈利能解释收益 |
| **1996** | Sloan | **应计异象**：应计利润高的公司收益低、现金流高的公司收益高——盈利**质量**重要 |
| **2013** | Novy-Marx | **毛利/资产（GP/A）**——"价值的另一面"：**毛利率**是最强的盈利因子 |
| **2015** | Fama-French | 把盈利因子 **RMW** 加入 **FF5** |
| **2015** | Hou-Xue-Zhang | q-factor 用 **ROE** 作为盈利因子 |

### 3.2 度量谱系【新增】

"盈利"不是一个指标，而是一族指标。选错度量，因子效果天差地别：

| 度量 | 公式 | 优点 | 缺点 | 学术地位 |
|---|---|---|---|---|
| **ROE** | 净利润 / 净资产 | 直观、q 理论直接对应 | 受**杠杆**影响（高负债也能推高 ROE）；净资产可能为负 | q-factor 采用 |
| **ROA** | 净利润 / 总资产 | 不受杠杆影响、更可比 | 未剔除应计噪声 | 常用辅助 |
| **GP/A**（毛利/资产） | (营收 − 营业成本) / 总资产 | **最"干净"**：不受利息、税、非经常损益、应计干扰；Novy-Marx 实证最强 | 忽略费用结构（不反映经营效率） | **Novy-Marx (2013) 主张的最强盈利因子** |
| **净利率 / 毛利率** | 利润 / 营收 | 反映定价能力与护城河 | 受行业结构影响大 | 质量因子常用 |
| **应计（Accruals）** | (净利润 − 经营现金流) / 总资产 | 衡量**盈利质量**，是"负面"指标（越低越好） | 波动大、需现金流数据 | Sloan (1996) |
| **扣非 ROE** | 扣非净利润 / 净资产 | **A 股最实用**：剔除一次性损益 | 需处理扣非数据 | 中国实务主流 |

**为什么 Novy-Marx 强调毛利率？** 净利润被**利息、税收、一次性损益、会计政策**层层污染；而**毛利 = 营收 − 营业成本**，位于利润表**最上游、被操纵空间最小**——它是"**最接近真实经营盈利能力**"的度量。这就是"**价值的另一面**"标题的含义：毛利率捕捉的盈利维度，和 B/M 捕捉的价值维度**互补而非重叠**。

### 3.3 成因：投资 CAPM（主流）+ 行为补充

**（A）投资 CAPM 解释——见第二节的正式推导**

分子 $\Pi_K$（边际盈利）↑ → 预期收益 ↑。ROE/毛利正是 $\Pi_K$ 的实证代理。

**（B）行为解释（辅助，三个渠道）**

| 渠道 | 机制 | 文献 |
|---|---|---|
| **PEAD（盈利公告后漂移）** | 盈利超预期的公司，股价在公告后**继续缓慢同向漂移**数周至数月——投资者**反应不足** | Ball-Brown (1968), Bernard-Thomas (1989) |
| **应计异象** | 投资者被"账面利润"迷惑，**高估应计**（非现金、易操纵）、**低估现金利润** | Sloan (1996) |
| **套利限制** | 盈利因子需读懂财报，分析成本高、做空成本高，错误定价难以被快速套利抹平 | 套利限制文献 |

**主流共识**：盈利因子**主要由投资 CAPM 解释**（理论驱动），行为解释是补充。这与价值因子（风险 vs 行为各占一半、至今无定论）形成鲜明对比。

### 3.4 实证：从美国到全球到 A 股

**美国**：
- **Novy-Marx (2013)**：GP/A 多头（高毛利）空头（低毛利）组合，**年化超额收益约 4%–5% 量级，夏普比率约 0.5**（文献报告的典型量级），在不少样本期**强于价值（HML）**。
- **FF5 (2015)，样本 1963/07–2013/12**：RMW 的月均溢价约 **0.25%–0.3%**（年化约 3%–3.6%），与 SMB、CMA 量级相当。
- **Sloan (1996)**：应计最高组 vs 最低组，**年化收益差约 10%** 量级。

**全球**：盈利溢价在主要市场普遍存在；**AQR 的 QMJ（Quality Minus Junk）** 把盈利、成长、安全（低波动/低应计）合成"质量"，在**全球多市场**都获得显著溢价。

**A 股（联系现实的关键）**：盈利因子**相对有效**，但**"盈利质量"与"财务真实性"是生死线**：

| A 股特点 | 对盈利因子的影响 |
|---|---|
| **高 ROE 有效性** | A 股高 ROE/毛利率公司长期表现更好，盈利因子能跑出超额 |
| **财务造假风险** | 账面利润可操纵（应计、关联交易、商誉），**必须 PIT + 现金流校验**（呼应 9/5 笔记） |
| **非经常性损益** | 净利润含大量**政府补贴、资产处置、投资收益**，须用**扣非**度量 |
| **行业差异** | 银行/地产/科技的盈利水平天然不同，必须**行业中性化** |
| **盈利的持续性** | A 股盈利波动大（周期性强），**盈利稳定性**本身也是一种信号（质量维度） |

> 💡 **现实启示**：A 股盈利因子的落地公式 = **扣非 ROE/毛利率** + **经营现金流/净利润校验** + **行业中性化** + **严格 PIT**。四者缺一，"高盈利"就可能只是"高账面利润"。

### 3.5 A 股落地实现（Tushare）【新增】

        return None

# ---- 3. 盈利质量校验：经营现金流 / 净利润 > 1 视为质量好 ----
# 需从 cashflow（经营现金流 n_cashflow_act）与 income（净利润 n_income）计算

# ---- 4. 行业中性化（用申万/中信行业分类）----
def industry_neutralize(factor_df, industry_map):
    """对因子做行业中性化：因子 ~ 行业哑变量，取残差"""

## 四、投资因子（§3.5）

### 4.1 起源：从"资产增长"到"投资因子"

| 时间 | 里程碑 | 内容 |
|---|---|---|
| **2004** | Titman-Wei-Xie | **资本支出**高的公司未来收益低 |
| **2008** | Cooper-Gulen-Schill | **资产增长率（asset growth）**：总资产增长最快的公司，未来收益显著更低 |
| **2015** | Fama-French | 把投资因子 **CMA** 加入 FF5 |
| **2015** | Hou-Xue-Zhang | q-factor 用 **I/A（投资/资产）** 作为投资因子 |

**方向是"反向"的**：资产增长越猛（资本开支大、并购多），未来收益越低。**做多"低投资"（保守）公司，做空"高投资"（激进扩张）公司。**

### 4.2 度量谱系【新增】

| 度量 | 公式 | 特点 | 文献 |
|---|---|---|---|
| **资产增长率** | $\Delta$总资产 / 期初总资产 | 最常用，覆盖**全部**投资渠道（资本开支 + 并购 + 营运资本） | Cooper-Gulen-Schill (2008) |
| **I/A（投资/资产）** | 资本开支 / 总资产 | q 理论的直接对应（$I_t/K_t$） | Hou-Xue-Zhang (2015) |
| **资本支出/折旧** | CapEx / Depreciation | 衡量"扩张 vs 维持"（>1 为扩张） | Titman-Wei-Xie (2004) |
| **净股票发行** | 股票发行 − 回购 | 公司融资行为也含投资信息（发股 = 扩张 + 高估） | Daniel-Titman (2006) |
| **净经营资产增长** | $\Delta$NOA / 期初 | 更聚焦**经营性**投资（剔除金融资产） | Hirshleifer et al (2004) |
| **应计 + 投资 复合** | — | 两者同源于"投资/增长"主题，可合成 | — |

**注意**：**资产负债表是时点值**（9/5 笔记），资产增长率不需要拆单季度；但它对**并购**极其敏感——一次大并购就能让资产翻倍，需结合"**是否毁价值**"判断（见下）。

### 4.3 成因：投资 CAPM（主导，见第二节）

分母 $a(I_t/K_t)$（调整成本）↑ → 预期收益 ↓。**高投资 = 低资本成本 = 低预期收益**——这是最优雅的解释。

**（B）行为补充**：

- **过度投资 / 帝国建造**：经理人为个人声望过度扩张（并购、建产能），损害股东价值（Jensen 1986 的自由现金流代理问题）；
- **投资者对扩张反应不足**：市场短期高估扩张的价值，之后回落；
- **"赢家诅咒"**：高投资常伴随高价并购，商誉减值风险在后；

### 4.4 实证：从美国到全球到 A 股

**美国**：
- **Cooper-Gulen-Schill (2008)**：资产增长率是**横截面最强的预测变量之一**，最低增长组显著跑赢最高增长组（等权口径下年化价差可达 **约 20%** 量级，含小盘股影响；三因子调整后仍显著）。
- **FF5 (2015)**：CMA 月均溢价约 **0.3%**（年化约 3.6%）量级；与 RMW 一起"**接管**"了价值因子的解释力。

**全球**：投资因子在主要市场普遍存在；与盈利因子共同构成 q 理论的"两翼"。

**A 股（联系现实的关键）**：

| A 股特点 | 对投资因子的影响 |
|---|---|
| **并购重组题材炒作** | 资产扩张常伴随题材炒作，**短期可能不跌反涨** → 需更长持有期验证 |
| **高再投资、低分红** | A 股"铁公鸡"多（高留存、高扩张），需区分**真投资**（有回报）vs **乱扩张**（毁价值） |
| **产能周期** | A 股制造业产能周期明显，投资因子在**周期下行期**尤为有效 |
| **PIT 要求** | 依赖资产负债表时点值，须公告日滞后（9/5 笔记） |

> 💡 **现实启示**：A 股投资因子的关键不是"投资多少"，而是"**投资回报率**"——**高投资 + 低 ROE = 烧钱扩张（做空）**；**高投资 + 高 ROE = 良性成长（可持有）**。这就是下一节"盈利 × 投资"矩阵的实战价值。

## 五、FF5 的构造细节与因子相关性【新增】

### 5.1 RMW 与 CMA 的 2×3 排序构造

FF5 延续 FF3 的 **2×3 排序**思路（补充篇 §4.1）：

```
RMW 构造：
  按规模 2 组（Small / Big，中位数分） × 按盈利 3 组（30/70 分位：Weak / Neutral / Robust）
  → 6 个组合
  RMW = (Small Robust + Big Robust)/2 − (Small Weak + Big Weak)/2

CMA 构造：
  按规模 2 组 × 按投资 3 组（30/70 分位：Conservative / Neutral / Aggressive）
  → 6 个组合
  CMA = (Small Conservative + Big Conservative)/2 − (Small Aggressive + Big Aggressive)/2
```

**设计要点**：
- "跨规模组平均"消除了**规模干扰**（和 HML 的构造逻辑一致）；
- 组合按**市值加权**、**NYSE 断点**、**月度再平衡**（补充篇 §4.4 的防前视协议）；
- 财务报表用 **t-6 月**前的年报数据，确保信息在期末已知。

### 5.2 因子相关性矩阵（理解 HML 冗余的关键）

FF5 各因子的典型相关系数（文献报告的量级，具体数值因样本期而异）：

| | Mkt | SMB | HML | RMW | CMA |
|---|---|---|---|---|---|
| **HML** | 低 | 低 | 1.00 | **约 0.24** | **约 0.70** ⚠️ |
| **RMW** | 低 | 低 | 约 0.24 | 1.00 | 约 0.14 |
| **CMA** | 低 | 低 | **约 0.70** ⚠️ | 约 0.14 | 1.00 |

> ⚠️ **CMA 与 HML 的相关性高达 0.7 左右**——这才是 HML 冗余的**直接原因**：CMA 已经"装下"了 HML 的大部分信息（低投资的公司往往就是高 B/M 的价值股）。9/4 笔记的正交化讲的就是如何量化这种冗余：**把 HML 对 RMW、CMA 正交化后，剩下的"纯价值"收益所剩无几。**

### 5.3 与 q-factor 的对照

| | FF5 (2015) | q-factor (2015) |
|---|---|---|
| 因子 | Mkt, SMB, **HML**, RMW, CMA | Mkt, ME, **I/A**, ROE |
| 驱动 | 实证发现 | q 理论推导 |
| 是否含价值 | 是（但冗余） | **否**（价值被投资/盈利替代） |
| 盈利度量 | 营业利润率（Operating Profitability） | ROE |
| 实证表现 | 与 q-factor 相当、高度相关 | 同左 |

**两者高度相关**恰好说明：**价值、盈利、投资这三个"基本面维度"在实证上高度重叠**——它们是同一枚硬币的不同面。

## 六、盈利 × 投资：合成"质量"（实战矩阵）

| 组合 | 公司画像 | 对应风格 | A 股实例类型 |
|---|---|---|---|
| **高盈利 + 低投资** | 现金牛：赚得多、不乱扩张 | **质量**（Quality） | 高 ROE、低资本开支的消费/公用事业 |
| 高盈利 + 高投资 | 良性成长：赚钱且扩张有回报 | **质量成长** | 扩张中的高端制造龙头 |
| 低盈利 + 低投资 | 守成/衰退型 | 防御 / 价值 | 低估值、低增长的成熟行业 |
| **低盈利 + 高投资** | **烧钱扩张**：乱花钱 | **"价值陷阱"风险** | 高负债扩张、商誉高企的公司 |

**关键理解**：**盈利因子管"赚不赚钱"，投资因子管"钱花得值不值"**。单独看任一维度都会被误导——
- 只看高盈利，可能买到"**高盈利但乱投资**"的烧钱公司；
- 只看低投资，可能买到"**不投资也不赚钱**"的衰退公司；
- **两者结合**才完整刻画"基本面成色"，这正是 A 股"**红利质量**""**质量成长**"指数的设计逻辑。

## 七、常见误区【新增】

| 误区 | 为什么错 | 正确做法 |
|---|---|---|
| **用净利润算 ROE** | 净利润含大量非经常性损益（政府补贴、资产处置） | A 股用**扣非 ROE**；美股可用营业利润率 |
| **忽略 PIT** | 用未来财报 → 前视偏差 → 纸面 α | `ann_date <= trade_date` 严格过滤 |
| **不做行业中性化** | 银行 ROE 天然低于消费，全市场排序会被行业结构主导 | 行业内标准化 / 行业中性化 |
| **把高投资一律做空** | 高投资 + 高 ROE 可能是良性成长 | 用"盈利 × 投资"矩阵区分 |
| **把盈利能力当"异象"挖** | 它是有理论根基的定价因子，不是免费午餐 | 理解它是 q 理论的推论，重点在**稳健估计**而非"发现" |
| **忽视应计/现金流** | 账面盈利与真实现金流可能严重背离（财务造假） | 用 **经营现金流/净利润** 做质量校验 |
| **认为 RMW/CMA 与 HML 独立** | CMA–HML 相关性约 0.7，严重共线 | 正交化后再看边际贡献（9/4 笔记） |

## 八、前沿发展【新增】

### 8.1 机器学习视角下的盈利/投资

- **Gu-Kelly-Xiu (2020)**：在用几十种 ML 方法预测股票收益时，**盈利/投资类特征（ROE、资产增长）在变量重要性排序中位居前列**——机器学习"独立地"再次确认了这两类基本面变量的价值。
- **IPCA（Kelly-Pruitt-Su 2019）**："**特征即协方差**"——盈利、投资这类特征，本质上是**时变风险暴露的载荷**。这与投资 CAPM 的"特征代理边际盈利/投资"在思想上一脉相承。

### 8.2 盈利/投资的"异象衰减"问题

- **Hou-Xue-Zhang (2020)** 的复制协议中，**投资与盈利类异象的存活率相对较高**（相比动量、部分价值类）——因为它们有理论支撑，不容易是纯数据挖掘。
- **McLean-Pontiff (2016)**：即便如此，发表后仍有衰减——**理论根基不等于免疫于套利**。

### 8.3 近年实践趋势

- **"质量"因子的崛起**：2020 年后，市场对"盈利稳定、低杠杆、现金流好"的公司给予持续溢价（"**质量 > 成长**"的风格切换）；
- **ESG 与质量的重叠**：ESG 评分中的治理（G）维度与盈利质量、投资纪律高度相关；
- **A 股的"红利 + 质量"**：高股息 + 高盈利稳定性 + 低资本开支，成为近年最受宠的风格组合——**正是盈利因子 × 投资因子的直接落地**。

## 十一、一句话总结

> 盈利因子管"**赚不赚钱**"（RMW/ROE/毛利，在 q 理论公式的**分子**），投资因子管"**钱花得值不值**"（CMA/资产增长，在**分母**）——两者**同源于一个方程式**，是 FF5 里**最有理论根基、因而最"干净"**的两根因子；
> 它们的实证地位靠一个关键数字支撑：**CMA 与 HML 相关性约 0.7** —— 价值溢价很大程度上就是"低盈利 + 低投资"的代理（HML 冗余）；
> 落到 A 股，盈利因子**较有效但须扣非 + 查现金流 + 守 PIT + 行业中性化**，投资因子**有效但须区分真投资与乱扩张**；两者交叉成"**质量矩阵**"——只有"高盈利 + 低投资"的现金牛，才是 A 股质量/红利风格真正坚实的底层。
