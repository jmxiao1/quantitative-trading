## 0. 两个因子在多因子模型版图中的位置

```

        │
1964 CAPM 诞生 ──→ 唯一因子：市场因子 MKT ──────────────┐ 3.2
        │                                              │
1981 Banz 规模异象（CAPM 解释不了！）                    │ 3.3
        │                                              │
1993 Fama-French 三因子 ──→ MKT + SMB + HML ←──────────┘
        │
之后：五因子、q-factor、……（"异象 → 因子化"成为方法论模板）
```

一句话定位：**市场因子是地基（系统性风险的定价），规模因子是第一个撼动地基的"异象"**——它把学术界从 CAPM 一因子的信仰中拉出来，直接催生了多因子模型。读懂这两个因子，就读懂了整个因子投资的方法论起源。

## 一、市场因子（MKT）

### 1.1 起源

**理论脉络（三步）：**

1. **Markowitz（1952）**：组合内相关性低的股票，分散化可以消灭**特质风险**，但消灭不了所有资产一起波动的部分——**系统性风险**。
2. **CAPM（Sharpe 1964 / Lintner 1965 / Mossin 1966）**：系统性风险不可分散，必须给补偿：

   $$E[R_i] - R_f = \beta_i \cdot (E[R_M] - R_f)$$

   市场因子的学术定义就此确立：**市场组合的超额收益**，β 只是个股对它的敏感度。
3. **Fama-French（1993）**：CAPM 的 α 塞不下（见 2.1 规模异象），于是加入 SMB、HML，但市场因子作为地基被完整保留——今天所有多因子模型的第一行都是它。

**Roll（1977）批评**：真正的"市场组合"（含人力资本、房产、全球资产）不可观测，实证只能用代理指数——所有对 CAPM 的检验其实是对"代理组合"的检验。这个批评解释了为什么各国市场因子表现不同。

**因子构造（A股实操口径）**：

| 构件 | 通行做法 | Tushare 实现 |
|---|---|---|
| 市场收益 R_M | 全市场指数市值加权收益：中证全指(000985.SH)、国证A指(399317.SZ)；Wind 用户用万得全A(881001.WI) | `pro.index_daily(ts_code='000985.SH')` |
| 无风险利率 R_f | 1年定存利率 / 3月SHIBOR / 短期国债 | `pro.shibor()` / `pro.deposit_rate()`（可能需积分）；教学可用定值近似 |
| 频率 | 月频（因子研究惯例） | 日收益 → 月复合 |

> ⚠️ **加权方式的坑**：用**等权**指数当市场因子，会偷偷混入小盘暴露（等权=超配小票），市场因子和规模因子就纠缠了。因子研究一律用**市值加权**全市场指数。

### 1.2 成因

- **正统解释：风险补偿**。系统性风险无法通过持有更多股票消除（2008、2015 谁都逃不掉），承担它必须有溢价。与之对照：单只股票的特质风险分散就没了，市场**不给补偿**——这一对比是理解"什么才配叫因子"的钥匙。
- **现实偏离：低β异象**。CAPM 预言 β 与收益严格线性，现实却长期"偏平"——高β没赚到相应溢价：
  - **杠杆约束**（Frazzini & Pedersen 2014, BAB）：不能加杠杆的投资者（含杠杆上限的公募）转而买高β股票"借β加杠杆"，把高β买贵、低β卖出便宜 → 低β组合风险调整后反而更好；
  - **彩票偏好**：高β股票常带暴富叙事，被散户系统性追捧高估。
- 结论：市场因子的溢价存在且必要，但 **β 并不是一条精确的定价直线**——这本身就是多因子模型存在的理由。

### 1.3 实证

**美国经典证据**：

| 研究 | 发现 |
|---|---|
| Black-Jensen-Scholes (1972)、Fama-MacBeth (1973) | β 与收益正相关，但斜率低于 CAPM 理论值（线偏平） |
| Baker-Bradley-Wurgler (2011)、Frazzini-Pedersen (2014) | 低β/低波动异象自 1926 年以来长期稳健 |

**A股**：β-收益关系更弱且不稳定——散户主导定价、卖空受限，高β在 2015 年杠杆牛市中领涨、在熊市中重挫。β 更像**烈度旋钮**而非收益预言：择时意义（仓位/防守）大于选股意义。

**现实联系（写笔记时实测）**：2025-09-05 上证指数收 3812.51 点（本机 `index_daily` 拉取）。买宽基 ETF（沪深300/中证500/中证1000）= 买入市场因子多头；指数增强基金 = 持有 β、卖出 α 的生意；量化私募的市场中性产品 = 做多选股组合、做空股指期货，把 MKT 对冲掉只留 α——**β 管理就是资产配置的主线**。

## 二、规模因子（SMB）

### 2.1 起源

- **Banz（1981，JFE）**：NYSE 1936–1975 样本，市值与**风险调整后**收益显著负相关——小公司更赚钱，而且 CAPM 的 β 解释不了。这是第一个"纯异象"出身的大发现（同期 Reinganum 1981；Keim 1983 又发现小公司一月效应）。
- **Fama-French（1993）**：把规模做成正式因子 **SMB（Small Minus Big）**，并给出经典构造：

  $$SMB = \tfrac{1}{3}(S/V + S/I + S/G) - \tfrac{1}{3}(B/V + B/I + B/G)$$

  即市值按中位数二分（S/B）× 账面市值比三分组（V/I/G）形成 **6 个组合**，SMB = 三个小组均值 − 三个大组均值。双分组的目的：**剥离价值暴露**，让 SMB 是"干净"的规模因子。
- **A股书本通行做法**：市值**单变量**排序分组（常见中位数二分或 30/40/30，以书为准），规模因子 = 小组等权收益 − 大组等权收益，**做多小、做空大**。
- **市值口径**：`daily_basic.total_mv`（总市值，FF 口径）/ `circ_mv`（流通市值）。A 股限售股差异大，两种口径会给出不同分组，回测中保持一致即可（自检题 7）。

### 2.2 成因（四类解释）

**① 风险补偿类**
- 小公司经营风险大、抗冲击弱（Chan & Chen 1991：产出风险），衰退期首当其冲；
- **流动性风险**（Amihud 2002）：小票买卖价差大、冲击成本高——本质是给流动性 provider 的补偿。**A 股语境下这是最重要的一条**（2024 年微盘股危机就是它的极端展演，见 2.3）；
- 信息风险（Merton 1987 投资者认知模型）：覆盖少、认知度低 → 要求补偿。

**② 错误定价 + 套利限制类**
- 忽视效应（Arbel & Strebel 1983）：机构覆盖少 → 定价效率低，聪明钱修复却受限（小票**容量小**、卖空难）——异象能长期存在的根本原因。

**③ 制度与中国特色类（A股规模因子的主轴）**
- **壳价值**：IPO 排队时代，上市资格本身值钱，小市值股票内嵌一张"借壳期权"→ 小盘超额里混着制度租金；
- 制度演进步步拆掉这张期权：2016.9 最严借壳新规 → IPO 常态化 → 2020 退市新规 → 2019 科创板试点注册制 → **2023.2 全面注册制** → 2024.4 新"国九条"强化退市。壳价值坍塌 = 小盘超额的构成发生质变。

**④ 数据挖掘与发表后衰减**
- Schwert（2003）：异象发表后常常"死给你看"；McLean & Pontiff（2016，JF）：因子收益发表后平均衰减近六成（58%）。**规模因子是这一定律的头号案例**——美股 1980 年代后 SMB 持续走弱、2000 年代以来长期接近零。

### 2.3 实证（美股 → A股时间线）

**美国**：Banz 原始样本强劲 → FF1993 中 SMB 显著（t 值 3 以上）→ 1980s 后逐代衰减 → 近 20 年美股 SMB 近乎归零，"Size is dead?"成为长期议题；国际市场（Fama-French 2012，23 国）规模溢价也普遍弱于价值与动量。

**A股时间线（联系现实，每段对应制度变化）**：

| 时期 | 规模因子表现 | 驱动因素 |
|---|---|---|
| 2007–2016 | 小市值黄金期，超额巨大 | 壳价值 + 并购重组潮 + 散户主导 |
| 2017–2018 | **大逆转**：沪深300 约 +22%，中证1000 约 −17% | 借壳收紧、IPO 提速、北向流入、MSCI 纳入、公募抱团白马 |
| 2019–2021初 | "以大为美"极致（核心资产/茅指数） | 外资定价权、机构化 |
| 2021–2023 | 微盘股策略连年大赚，量化拥挤 | 壳价值回潮 + 量化资金涌入小微盘 |
| **2024 年 1–2 月** | **微盘股流动性危机**：雪球集中敲入 + DMA 杠杆踩踏，微盘指数短期回撤超四成，监管出手（汇金增持中证500/1000 ETF、规范 DMA），春节后 V 型反转 | **小溢价 = 流动性风险溢价，危机时加倍兑现**；拥挤交易的反身性 |
| 2024.4 至今 | 新国九条再度冲击小微盘后逐步修复 | 退市执行常态化，风险重定价 |

> 💡 **核心教训**：A股"长期小盘赢"的历史回测，很大部分是**壳价值时代的制度红利**——制度环境变了，历史规律不可外推。规模因子在 A 股的时变性极强，与其说是"因子"，不如说是一段**制度周期的影子**。

### 2.4 接入既有管线（Tushare）——SMB 完整构造

数据要点：`daily_basic(trade_date=月末交易日)` **一次调用返回全市场市值**（与 §3 抓日线截面同理），20 个调仓日只需 20 次调用（本账号限频 1 次/小时，分多天补齐或升积分后一次拉全）。

```python
# ① 每月末市值截面（缓存到 cache/05_mv_YYYYMMDD.csv，本机已有 20250829 演示）
mv = pro.daily_basic(trade_date='20250131', fields='ts_code,total_mv')

# ② SMB 月度收益（接 Tushare学习笔记 §4 收益面板 ret_wide、§1 月末交易日）
def smb_returns(ret_wide, mv_sections, q_small=0.3, q_big=0.3):
    """q_small/q_big: 按分位切小/大组（书本口径以书为准）；等权；做多大减小取负"""
    dates = sorted(mv_sections)
    rows = []
    for d, d_next in zip(dates[:-1], dates[1:]):
        mv = mv_sections[d].set_index('ts_code')['total_mv']     # 调仓日"当时"的市值(PIT!)
        r_next = ret_wide.loc[d_next]                            # 下个自然月的收益(§5.1 对齐)
        small = mv[mv <= mv.quantile(q_small)].index
        big   = mv[mv >= mv.quantile(1 - q_big)].index
        rows.append({'rebalance_date': d,
                     'small': r_next.reindex(small).mean(),
                     'big':   r_next.reindex(big).mean()})
    s = pd.DataFrame(rows)
    s['SMB'] = s['small'] - s['big']
    return s

# ③ 检验衔接：个股超额收益对 MKT、SMB 回归（时序回归），
#    或 SMB 自身的分组月收益序列做统计检验（均值/t值/累计净值）
```

> ⚠️ 三个严谨性开关（全部来自第一部分笔记）：分组市值必须用**调仓日当时**截面（PIT，§10.4）；停牌股当期无收益保留 NaN（§9.3）；月频演示用月末收盘价近似成交，严谨版本用次日开盘成交并计冲击成本（小票冲击成本正是 §2.2 的流动性溢价本体）。

## 三、两因子的联系与复盘

**方法论主线**：市场因子给出定价基准 → 规模异象戳穿 CAPM → FF 把异象"因子化"进多因子模型 → **此后每个新异象（价值、动量、盈利、投资……）都走 SMB 的老路**：发现 → 风险还是错误定价之争 → 构造因子 → 检验 → 衰减。3.2 和 3.3 不只是两个因子，而是整部因子投资史的缩影。

**风险 vs 异象之争**：规模因子是最经典的战场——Fama 一派说"小公司承担了被忽视的风险"，行为派说"市场忽视+套利限制"。2024 年初微盘股危机给了一个 A 股注脚：**平时是溢价，危机时是风险**，两种叙事在时间轴上轮流占上风。

**现实产品映射**：

| 因子 | 现实载体 |
|---|---|
| MKT（做多市场） | 宽基 ETF（沪深300/中证500/中证1000）、指数增强、股债配置的仓位决策 |
| 对冲 MKT | 市场中性策略（多头选股组合 + 空头股指期货） |
| SMB（做多小盘） | 中证1000/2000 指数基金、微盘股量化产品（2024 危机即拥挤度的代价） |
| 低β异象 | 红利/低波动"防御型"产品 |
